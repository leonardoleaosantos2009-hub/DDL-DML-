# 🗄️ Portfólio SQL

Este repositório reúne projetos e estudos desenvolvidos durante minha
aprendizagem de Banco de Dados e SQL.

Os projetos apresentam diferentes cenários de sistemas, permitindo
praticar conceitos de modelagem, criação e manipulação de bancos de dados.

## 📚 Projetos

### 🛒 Loja Virtual
Banco de dados desenvolvido para representar as operações de uma loja virtual.

**Conceitos praticados:**
- Modelagem de banco de dados
- Criação de tabelas
- Chaves primárias
- Chaves estrangeiras
- Relacionamentos
- Comandos SQL

### 🏫 Sistema Escolar
Banco de dados para representar um sistema escolar.

**Conceitos praticados:**
- DDL
- DML
- Criação de tabelas
- Inserção de dados
- Relacionamentos
- Consultas SQL

### 🦷 Consultório Odontológico
Modelagem de banco de dados para gerenciamento de um consultório odontológico.

**Conceitos praticados:**
- Modelagem de dados
- Relacionamentos
- Chaves primárias e estrangeiras
- Criação e manipulação de tabelas

### 🔧 Oficina Mecânica
Banco de dados desenvolvido para representar o funcionamento de uma oficina mecânica.

**Conceitos praticados:**
- Modelagem relacional
- Criação de tabelas
- Relacionamentos
- Integridade dos dados
- SQL

### 🛍️ Banco de Dados de Varejo
Projeto de banco de dados voltado para um cenário de varejo.

**Conceitos praticados:**
- DDL
- DML
- Criação de banco de dados
- Criação de tabelas
- Inserção de dados
- Relacionamentos

## 🛠️ Tecnologias

- SQL
- MySQL
- MySQL Workbench

# 🏥 Banco de Dados - Consultório Médico

## 📌 Sobre o projeto

Projeto de criação de banco de dados para representar um sistema
de consultório médico.

O projeto tem como objetivo estruturar os dados necessários para
organizar informações de um ambiente de atendimento médico.

## 🎯 Objetivo

Praticar a criação de bancos de dados relacionais utilizando SQL,
aplicando conceitos de estruturação e organização de dados.

## 🛠️ Tecnologias

- SQL
- MySQL
- MySQL Workbench

## 📚 Conceitos praticados

- Criação de banco de dados
- Criação de tabelas
- Definição de tipos de dados
- Chaves primárias
- Chaves estrangeiras
- Relacionamentos
- Integridade dos dados

## ▶️ Como executar

1. Abra o MySQL Workbench.
2. Abra o script do projeto.
3. Execute os comandos SQL.
4. Verifique as tabelas e estruturas criadas.

## 📌 Status

Concluído como projeto de estudo.

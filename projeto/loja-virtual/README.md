# 🛒 Banco de Dados - Loja Virtual

## 📌 Sobre o projeto

Projeto de banco de dados desenvolvido para representar as operações
de uma loja virtual.

O banco foi estruturado para armazenar informações relacionadas a
clientes, produtos, pedidos e demais entidades necessárias ao sistema.

## 🗂️ Modelagem

O banco utiliza um modelo relacional, com tabelas relacionadas por
chaves primárias e estrangeiras.

## 🛠️ Tecnologias

- MySQL
- SQL
- MySQL Workbench

## 📚 Conceitos utilizados

- CREATE DATABASE
- CREATE TABLE
- PRIMARY KEY
- FOREIGN KEY
- INSERT
- SELECT
- Relacionamentos entre tabelas

## 🚀 Como executar

1. Abra o MySQL Workbench.
2. Abra o arquivo `loja_virtual.sql`.
3. Execute o script.
4. Verifique as tabelas criadas no banco de dados.

# 🔧 Banco de Dados - Oficina Mecânica

## 📌 Sobre o projeto

Projeto de banco de dados desenvolvido para representar
o funcionamento de uma oficina mecânica.

O objetivo é estruturar informações relacionadas aos serviços
e operações de uma oficina utilizando um banco de dados relacional.

## 🎯 Objetivo

Aplicar conceitos de banco de dados em um cenário prático,
desenvolvendo uma estrutura organizada para armazenamento de dados.

## 🛠️ Tecnologias

- SQL
- MySQL
- MySQL Workbench

## 📚 Conceitos praticados

- Modelagem relacional
- Criação de banco de dados
- Criação de tabelas
- PRIMARY KEY
- FOREIGN KEY
- Relacionamentos
- Tipos de dados
- SQL

## ▶️ Como executar

1. Abra o MySQL Workbench.
2. Abra `oficina_mecanica.sql`.
3. Execute o script.
4. Verifique as tabelas e relacionamentos criados.

# 🛒 Banco de Dados de Varejo

## 📌 Sobre o projeto

Este projeto consiste na criação e manipulação de um banco de dados
voltado para um cenário de varejo.

O projeto foi desenvolvido utilizando SQL e está dividido em duas
partes principais: criação da estrutura do banco de dados (DDL) e
manipulação dos dados (DML).

## 📂 Arquivos

### `criacao_do_banco_de_dados_do_varejo.sql`

Arquivo responsável pela criação da estrutura do banco de dados
de varejo.

Nele são definidos os elementos necessários para estruturar o banco,
incluindo a criação do banco de dados e suas tabelas.

### `DML_do_banco_do_varejo.sql`

Arquivo responsável pela manipulação dos dados do banco de varejo.

Nele são utilizados comandos SQL para inserir e manipular registros
nas tabelas criadas.

## 🧱 DDL

**DDL (Data Definition Language)** é utilizada para definir e modificar
a estrutura do banco de dados.

Entre os conceitos trabalhados estão:

- `CREATE DATABASE`
- `CREATE TABLE`
- `PRIMARY KEY`
- `FOREIGN KEY`
- Definição de tipos de dados
- Estrutura das tabelas

## 📝 DML

**DML (Data Manipulation Language)** é utilizada para manipular os
registros armazenados no banco de dados.

Comandos trabalhados:

- `INSERT`
- `UPDATE`
- `DELETE`

## 🛠️ Tecnologias

- SQL
- MySQL
- MySQL Workbench

## ▶️ Como executar

1. Abra o MySQL Workbench.
2. Execute primeiro o arquivo
   `criacao_do_banco_de_dados_do_varejo.sql`.
3. Após a criação da estrutura do banco, execute o arquivo
   `DML_do_banco_do_varejo.sql`.
4. Verifique as tabelas e os registros inseridos.

## 🎯 Objetivo

O objetivo deste projeto é praticar a criação de um banco de dados
relacional e a manipulação de dados através de SQL.

## 📚 Conceitos aprendidos

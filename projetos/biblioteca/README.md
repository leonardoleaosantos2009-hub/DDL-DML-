# 📚 Banco de Dados - Biblioteca

## 📌 Sobre o projeto

Este projeto consiste na criação de um banco de dados para representar
o funcionamento de uma biblioteca.

O objetivo é organizar e armazenar informações relacionadas ao
gerenciamento de uma biblioteca utilizando SQL.

## 🎯 Objetivo

Praticar a criação e estruturação de um banco de dados relacional,
aplicando conceitos fundamentais de SQL.

## 🛠️ Tecnologias

- SQL
- MySQL
- MySQL Workbench

## 📚 Conceitos praticados

- Criação de banco de dados
- Criação de tabelas
- Tipos de dados
- Chaves primárias
- Chaves estrangeiras
- Relacionamentos
- Comandos SQL

## ▶️ Como executar

1. Abra o MySQL Workbench.
2. Abra o arquivo `biblioteca.sql`.
3. Execute o script.
4. Verifique o banco de dados e as tabelas criadas.
